# Creeper Golem Mod

Add a unique Creeper Golem to your Minecraft world.

## Features

- Adds a new Creeper Golem entity to the game
- Creeper Golem explodes upon death

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/creeper-golem-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with Fabric Loader.

## Usage

- The Creeper Golem will spawn naturally in the world.
- It will attack players and other mobs like an Iron Golem.
- When the Creeper Golem dies, it will explode.

## Configuration

Currently, there are no configuration options for this mod. Future updates may include configurable spawn rates and explosion power.
